# Bellevie Hotel - CMS & Hotel Management System

A complete Laravel 11 hotel management and reservation system with integrated CRM.

## Features

- Complete hotel room and booking management
- Guest CRM with VIP status tracking
- Blog publishing system
- Gallery management
- Booking calendar
- Revenue analytics
- Admin dashboard
- Cloudinary integration for image uploads

## Installation

1. Clone repository
2. Run `composer install`
3. Copy `.env.example` to `.env` and configure
4. Run `php artisan migrate --seed`
5. Access admin at `/admin/login`
